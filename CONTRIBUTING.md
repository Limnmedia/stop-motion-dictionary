# Contributing

The SQLite database is the committed delivery artifact. Changes to dictionary data must be reproducible from the Logseq source with `migrate_logseq.py` and must pass `validate_database.py` before review.

Follow [Dictionary Provenance and Retention](PROVENANCE_AND_RETENTION.md) before adding recovered source material or archival exports. Git is not a complete workstation backup.

Use a feature branch and pull request for changes. Do not commit Logseq configuration, AppleDouble files, temporary exports, or unrelated company material.
